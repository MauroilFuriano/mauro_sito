---

## Tecnica Più Usata nel 2026

**Gradient Mesh Animato + Noise/Grain Overlay**

- Visivamente impattante senza WebGL complesso
- Ottima performance su mobile
- Implementabile con CSS moderno
- Abbinabile a Framer Motion o GSAP
- Compatibile con dark theme

---

## Tecnica Più Professionale Percepita

**WebGL Fluid Shader / GLSL Flowing Noise** (rating: 5/5)

Richiede: GLSL, ottimizzazione mobile, 2-5 giorni di sviluppo.

Secondo livello (4.5/5): **Three.js con geometrie reattive**

## Raccomandazione per MAURO.EXE

### Tecnica: "Aurora Gradient Mesh + Scanline Noise"

**Descrizione:** Sfondo nero profondo con due blob — cyan + purple — animati lentamente come un'aurora boreale digitale. Overlay di noise texture che evoca uno schermo CRT/terminale.

| Criterio | Valore |
|----------|--------|
| Coerenza col brand `.EXE` | Alta — evoca terminale/CRT |
| Costo implementativo | Medio-basso (2-4 ore) |
| Performance | Ottima (CSS puro) |
| Unicità visiva | Alta nel contesto italiano |
| Professionalità percepita | 4.5/5 |
| Compatibilità mobile | Perfetta |

### Alternative per priorità

1. **Aurora CSS puro** ← consigliata — rapida, performante, coerente
2. **Particelle Three.js ridotte** — +1 giorno di sviluppo
3. **GLSL flowing noise cyan/purple** — massimo impatto, +3 giorni
4. **Video background** — sconsigliato per dev portfolio

---

> **Conclusione:** Nel 2026 il gold standard è il **gradient aurora animato con noise overlay** su dark background. Per MAURO.EXE, il combinato **cyan `#06b6d4` + purple `#7c3aed`** su nero profondo con noise CRT posiziona il sito al livello dei migliori portfolio internazionali.
